# Step 3: RISC-V cross-compilation

Cross-compile the generated Gemmini MLF and runtime application into a static RISC-V Linux ELF.

## Environment

The scripts use the pinned Gemmini software headers under `third_party/gemmini-rocc-tests`.
The RISC-V Linux cross-compiler `riscv64-linux-gnu-gcc` must be available in `PATH`.

## Run without LUT

From the repository root:

```bash
step3_cross_compile/build_elf.sh
```

## Run with LUT

From the repository root:

```bash
step3_cross_compile/build_lut_elf.sh
```

Each script uses the latest matching MLF run generated by Step 2.

## Hardware configuration

The default Gemmini configuration is DIM 16, 512 KiB scratchpad, and 256 KiB accumulator.
Override it with environment variables when needed:

```bash
DIM=16 SCRATCHPAD_KB=512 ACCUMULATOR_KB=256 \
  step3_cross_compile/build_lut_elf.sh
```

## Output

The generated executable is written under:

```text
generated/elf/
```
